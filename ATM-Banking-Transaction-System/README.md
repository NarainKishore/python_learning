# ATM Banking & Transaction System

A Python-based ATM simulation project created to practice `while` loops, conditions, user input, counters, accumulators, and transaction processing.

## Features

* PIN authentication with 3 attempts
* Account lock after 3 incorrect PIN attempts
* Check account balance
* Deposit money
* Withdraw money
* Balance validation for withdrawals
* Transaction summary
* Deposit and withdrawal counters
* Total deposited and withdrawn amounts
* Exit option

## Python Concepts Used

* Variables
* `input()` and type conversion
* `while` loops
* `while True`
* `if / elif / else`
* `break`
* Logical operators
* Counters
* Accumulators
* Input validation
* f-strings

## Learning Objective

The main objective of this project is to apply Python `while` loop concepts in a realistic banking application and understand how loops, conditions, counters, accumulators, and user input work together in a complete program.
